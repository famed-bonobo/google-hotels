# Changelog

## 0.1.0 (2026-10-29)

First release.

- `search()` with every Google Hotels filter, paging up to 1,000 hotels, and every booking site's offer per hotel.
- `hotel()` by Google Hotels link, property token or name, with the full hotel page.
- `price_calendar()`, `reviews()`, `photos()` and `city_report()`.
- `AsyncGoogleHotels` with the same methods, and the `google-hotels` command line.
